# Financial metrics reference

Read this only when a question needs a definition or a caveat. Keep answers in the user's
language; the terms below give both.

| Metric | 中文 | Formula | Watch out for |
|---|---|---|---|
| Revenue growth (YoY) | 营收同比增长 | (this period − same period last year) / last year | Acquisitions, currency changes, restated figures |
| CAGR | 复合年增长率 | (end / start)^(1/years) − 1 | Undefined if start or end ≤ 0; hides volatility |
| Gross margin | 毛利率 | gross profit / revenue | Cost classification differs across companies |
| Operating margin | 营业利润率 | operating income / revenue | One-off items; A股"营业利润"包含投资收益等 |
| Net margin | 净利率 | net income attributable to parent / revenue | Use 归母净利润 for A股, not 净利润 including minorities |
| ROE | 净资产收益率 | net income / average equity | Inflated by leverage and buybacks; state which equity base |
| P/E (TTM) | 市盈率（TTM） | price / trailing-twelve-month EPS | Meaningless when EPS ≤ 0; TTM vs forward vs static (静态) differ |
| P/B | 市净率 | price / book value per share | Less useful for asset-light businesses |
| Dividend yield | 股息率 | dividends per share (last 12 months) / price | Special dividends distort it |
| Free cash flow | 自由现金流 | operating cash flow − capital expenditure | Definitions vary; say which one you used |

Where to find primary figures:

- A股: 巨潮资讯网 cninfo.com.cn（定期报告、公告）, 上交所 sse.com.cn, 深交所 szse.cn
- 港股: 披露易 hkexnews.hk
- US: SEC EDGAR (10-K annual, 10-Q quarterly, 8-K events)
- Company investor-relations pages for presentations and earnings releases

Reported (audited annual report) beats unaudited quarterly, which beats media summaries, which
beat forecasts. Say which kind each number is.
